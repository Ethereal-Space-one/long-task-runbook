# 状态恢复与复核

## 从检查点恢复

1. 从接手入口先读总目标与停止点、当前检查点和下一项任务，核对当前用户指派。按本轮决定的需要再查台账、项目规范和原件。长对话摘要、旧指派和其他会话的交接文字用于定位原件。
2. 对照实际状态。按项目查分支、提交、工作区、文件内容和校验原件。有外部作业时先查已有作业或回执的实际状态。输入版本不同、报告无法定位、操作结果不明或写入者仍在工作时，先确认受影响范围。
3. 处理记录冲突。用户最新授权决定可继续的范围。验收以对应当前输入的真实交付物及验收原件为准。检查点、台账和实际产物不一致时，按最后能证实的结果恢复，补写差异和下一动作。文件存在、命令提交成功或工具返回成功各自只证明相应一步。
4. 接续第一个依赖已经满足的未完成项。对仍在运行的工作继续跟进。外部操作结果不明时，先根据现有作业 ID、对象状态或回执查询。只有确认需要重试且具备授权和防重条件时才重试。

在自然断点更新同一个检查点，例如交稿冻结、重要检查完成、返修后、停止或上下文切换前。留下本轮实际完成的成果、证据位置和下一条可执行动作。任务未收口时记录进行中及继续位置。暂停时记录已经发生的外部操作及是否仍在运行，按用户指示和操作能力处理。

## 复核和验收

- 先固定本次审核对象和版本。把当前交付物与范围、验收项和原始证据对照。已有项目专用验证时，使用该验证及其真实判定字段。退出码、待处理数量、覆盖结果和审核结论分别读取。
- 审核者记录具体问题、证据位置、影响范围和返修条件。执行者集中修正后复检变更及受影响的直接依赖。要求独立审核而暂时缺少审核者时，交付现有成果与自检结果，并把独立审核如实留在待处理项。
- 复用之前的结果时，确认输入版本、被验收内容、验证条件和相关依赖仍适用，并引用原始验收位置。局部变更定向重验。无法定位影响边界时，扩大到必要的验证范围。
- 按任务条件区分已完成、部分完成、待复核和受阻。缺口能与其他交付隔离时，按用户范围交付已完成部分。阶段转换或外部变更以当前授权与实测条件为准。

## 当前检查点的最少信息

可直接填入现有进度记录。

| 字段 | 写法 |
| --- | --- |
| 授权和停止点 | 当前允许执行的任务与明确的交回位置 |
| 位置和输入 | 实际工作目录或对象、版本标识、必要的工作区差异 |
| 当前状态 | 正在做的任务、写入者、已验收项及原件链接 |
| 最近检查 | 对应输入、验证方式、实际结果与仍未满足的条件 |
| 后续 | 未完成项、阻断范围、下一条可执行动作或待决定问题 |

用于提交、发布或可重复触发的外部操作，可行时先记录目标、动作和可查回的操作标识。工具支持幂等键时一并记录。提交返回后及时保存回执或对象标识。多处记录更新中断时，先依据原件重新核对，再同步同一个当前检查点与相关台账。
